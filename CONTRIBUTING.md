# Contributing

The easiest way: **open an issue** using one of the templates
(report a problem / add a solution / correction). Maintainer will fold accepted
submissions into the `kb/*.md` files, crediting you by name (never email).

Entry format used throughout:

```
## <short title>
*YYYY-MM-DD · original list thread: "<subject>" · status: solved|partial|unresolved*
- **Symptom:** what you observed
- **Likely cause:** what it turned out to be (or best hypothesis)
- **Fix / suggestions:** what actually fixed it, incl. part numbers if known
- **Credit:** asked by <name>; answered by <names>
```

House rules:
- Summaries only — don't paste raw list emails.
- Names for credit are fine; **no email addresses** in this repo.
- Keep part numbers, voltages, and prices exactly as reported.
