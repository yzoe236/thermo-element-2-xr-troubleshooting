# Contributing

Open an issue using the Report a problem, Add a solution or Correction template.
Accepted reports are summarized in the subsystem files without participant names.

Entry format:

```
## <short title>
*YYYY-MM-DD · original list thread: "<subject>" · status: solved|partial|unresolved*
- **Symptom:** what was observed
- **Likely cause:** confirmed cause, or an explicitly labelled hypothesis
- **Fix / suggestions:** distinguish completed repairs from proposed checks
```

House rules:

- Write English summaries; do not paste raw list emails or private service correspondence.
- Omit personal names, email addresses, telephone numbers, signatures and identifying institutional details. Do not request personal credit in entries.
- Keep technical manufacturer names, part numbers, voltages, units and prices as reported. State the date and distinguish user reports from manufacturer specifications.
- Preserve later corrections. Do not turn an unanswered suggestion into a confirmed solution.
- Retain the source subject and date where they contain no personal identifiers.
- Add ⏳ to explicitly unresolved entries and synchronize README, subsystem counts and unresolved.md.
- GitHub issues are public; check text and attachments for personal information before submitting.
